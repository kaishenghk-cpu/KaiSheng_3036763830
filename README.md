# Minimum wages and employment

Replication of Card and Krueger (1994), Tables 2-4 and Figure 1, with an extension testing whether employment responses differ between company-owned and franchised restaurants.

## Reproduce

Use Python 3.11 or newer. From the repository root:

```bash
python -m pip install -r requirements.txt
python code/run_all.py
```

Place the unmodified course package at `data/raw/01_DID/data/public.csv`, retaining its numbered folder and filename. Alternatively extract the original ZIP at the repository root to create `01_DID/data/public.csv`. The script accepts either location and checks that duplicate inputs agree. No login or network access is used by the analysis.

The course Package 01 was supplied by the student. Its README and data dictionary are retained in `data/raw/01_DID/`. Obtain the input from the authorized course download, or request access from the teaching team after the download window. No course download link or row-level input is published. The Princeton public replication materials are an alternative source, but their file format must first be checked against the course CSV; they are not silently substituted.

## Data treatment

Keep all 410 rows. `SHEET` alone is not a unique identifier; the two rows numbered 407 refer to different states and chains. A generated row identifier preserves them. FTE = EMPFT + NMGRS + 0.5 EMPPT. Permanent closures have zero follow-up employment; temporary closures are missing in the baseline and zero only in the designated sensitivity case. Never replace an ordinary missing employment component with zero.

Table 4 retains permanent closures even though their follow-up wage is missing, yielding 357 observations. Conventional OLS standard errors are used to compare with the paper; HC1 sensitivity estimates are also reported. There are only two states, so these are not state-cluster-robust policy inference.

See `report.pdf` for all results, discrepancies, and identification limitations. Output tables are computed from input data; published benchmark values are used only in comparison tables and validation checks, never as estimated output. The figure uses explicit 10-cent wage intervals and a final 5.50+ interval, documented in its source CSV.
